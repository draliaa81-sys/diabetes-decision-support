# Data

- `diabetes.csv`: the original Pima Indians Diabetes dataset (768 patients, 9 columns). Source: [UCI / Kaggle](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)
- `diabetes_cleaned.csv`: the same data after replacing impossible zeros (Glucose, BloodPressure, SkinThickness, Insulin, BMI) with the median of each column. See `notebooks/00_data_cleaning.ipynb`.
