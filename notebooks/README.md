# Notebooks

Run them in this order:

1. `00_data_cleaning.ipynb`: replace impossible zero values and save the cleaned data
2. `01_bfs_triage.ipynb`: find 20 high-risk patients with Breadth-First Search
3. `02_rule_based_system.ipynb`: explainable IF-THEN risk rules
4. `03_decision_tree.ipynb`: Decision Tree classifier, confusion matrix and feature importance
